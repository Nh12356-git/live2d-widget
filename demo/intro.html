FEATURES

功能特性

看板娘不只是装饰，它还能陪你聊天、玩耍、记录瞬间。

一言 / 消息气泡

支持一言（hitokoto）与随机消息，气泡显示在模型上方，可自定义优先级与 HTML 富文本。

模型切换

多模型一键切换，服务器自动扫描 model 目录，新增模型无需改代码，刷新即用。

换装贴图

同一模型多套贴图自由切换，随时给看板娘换一身新衣服。

一键截图

把看板娘和页面一起截图保存，留下可爱瞬间，支持拖拽到任意位置再截。

拖拽 & 布局

开启拖拽后可自由摆放看板娘位置，内置左侧/右侧布局与缩放控制。

小行星游戏

内置小行星躲避小游戏，无聊时点一点，和看板娘一起打发时间。

MODELS

模型自备

本项目不内置模型，模型需由你自行提供并放入 model/ 目录。

自行放置模型

将你的 Live2D 模型（含 .model3.json 配置文件）整体放入项目 model/ 目录即可，无需修改任何代码。

刷新即自动识别

服务器启动时会自动扫描 model/ 目录并生成模型列表，放入新模型后刷新页面即可立即使用。

设置中一键切换

模型就绪后，点击看板娘设置 → 选择模型即可切换，支持多模型与换装贴图自由搭配。

ARCHITECTURE

技术架构

前端渲染 + 后端代理，资源不直接暴露。

浏览器 → Express Server → model/ 资源
  • 模型文件通过 /api/model/file/* 代理，隐藏真实路径，杜绝直接暴露
  • 路径穿越防护 + 文件类型白名单 + /model 直连 403
  • TypeScript + Rollup 构建，产出轻量 autoload.js 一键接入
  • 基于 Live2D Cubism 5 SDK 渲染，WebGL 加速
  • 模型列表由 /api/model/list 自动扫描返回，新增模型零配置
  • 全静态本地资源，无外部 CDN 依赖，可完全离线部署
GET STARTED

快速上手

三步接入任意网页，让看板娘入住你的站点。

接入示例
<!-- 1. 部署并启动服务 -->
npm install
npm run build
npm start
# 访问 http://localhost:3000

<!-- 2. 在页面 body 末尾引入 -->
<script type="module" src="/dist/autoload.js"></script>

<!-- 3. 添加模型：放入 model/ 目录即自动识别 -->
model/
└── mymodel/
    ├── mymodel.model3.json
    ├── mymodel.moc3
    └── texture_00.png

使用提示

  • 切换模型 点击设置 → 选择模型，实时生效
  • 换装 在设置中选择贴图，切换服装
  • 消息气泡 支持优先级、时长、HTML 富文本
  • 拖拽 在设置中开启后自由摆放
  • 自定义端口 通过环境变量 PORT 指定
  • 生产部署 可用 PM2 守护 + Nginx 反向代理
